# W4D3: Model Serialisation - joblib & pickle

## Objective

Train a machine learning model, save it using `joblib` and `pickle`, reload both saved models, and verify that their predictions match the original model.

## Tools and Technologies

- Python 3.11
- scikit-learn
- joblib
- pickle
- pytest

## Implementation

- Used the built-in Breast Cancer Wisconsin dataset.
- Trained a Random Forest classifier with 100 estimators.
- Split the data into training and testing sets using an 80:20 ratio.
- Saved and reloaded the trained model using both serialisation methods.
- Compared the original and reloaded model predictions.

## Testing

Three automated tests verify:

1. joblib preserves model predictions.
2. pickle preserves model predictions.
3. The model returns the expected number of valid class predictions.

## Result

All three automated tests passed. The main script should also be executed successfully to verify both serialisation workflows and generate the saved model files.

## Files

- `model_serialisation.py` — training and serialisation workflow.
- `test_model_serialisation.py` — automated tests.
- `outputs/` — saved model files generated by the script.
