# Data Loading, Cleaning & Inspection

## Objective

To load, inspect, and clean a CSV dataset using Pandas.

## Tasks Completed

- Loaded CSV data using Pandas
- Inspected the dataset
- Checked missing values
- Removed missing values
- Removed duplicate rows
- Replaced missing values
- Used forward fill
- Performed basic data cleaning
- Checked and handled age values

## Dataset

The dataset contains information about names, age, city, salary, and department.

## Tools Used

- Python
- Pandas
- NumPy
