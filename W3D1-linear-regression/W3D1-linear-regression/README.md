\# W3D1: Linear Regression — Scikit-Learn



\## Objective

Train and evaluate a Linear Regression model using Scikit-Learn.



\## Dataset

California Housing dataset.



\## Work completed

\- Loaded the dataset and split it into training and testing sets.

\- Trained a Linear Regression model.

\- Printed model coefficients and intercept.

\- Evaluated the model using MSE, RMSE, MAE, and R².



\## Result

\- MSE: 0.4818

\- RMSE: 0.6941

\- MAE: 0.52

\- R²: 0.642



\## Tools

Python, NumPy, Pandas, Matplotlib, Scikit-Learn.
